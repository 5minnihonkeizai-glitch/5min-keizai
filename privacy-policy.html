プライバシーポリシー

「5分でわかる日本経済」（以下「当チャンネル」）は、ブログ（https://5minkeizai.blogspot.com/）、YouTube チャンネル（@5min_nihonkeizai）および TikTok で日本経済の解説コンテンツを公開しています。本ポリシーは、当チャンネルの運営と、当チャンネルが使用する投稿用アプリケーション「5min Keizai Uploader」における情報の取り扱いを定めるものです。

1. 投稿用アプリケーションが利用する Google ユーザーデータ

投稿用アプリケーションは、当チャンネル運営者本人の Google アカウントでのみ使用し、運営者以外のユーザーのデータにはアクセスしません。Google の OAuth 同意画面で許可された次の範囲だけを利用します。

  • Blogger：当ブログへの記事の下書き作成・投稿、およびブログ情報の確認
  • YouTube：当チャンネルへの動画のアップロード、および投稿先チャンネルとアップロード状況の確認（誤った投稿先や重複投稿の防止のため）

取得したデータは上記の目的にのみ使用し、広告、販売、第三者への提供、または AI モデルの学習には使用しません。

2. 保存と管理

Google から発行される認証トークンは、運営者の管理する端末の macOS キーチェーンにのみ保存し、外部のサーバーには保存しません。パスワードは保存しません。認証はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から取り消すことができます。

3. Google API サービスのユーザーデータに関するポリシー

投稿用アプリケーションによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

4. ブログの閲覧について

当ブログは Google の Blogger で運営されています。閲覧時のアクセス情報や Cookie の取り扱いは、Google のプライバシーポリシーに従います。当チャンネルが閲覧者の個人情報を独自に収集することはありません。

5. お問い合わせ

本ポリシーに関するお問い合わせは、5min.nihonkeizai@gmail.com までご連絡ください。
